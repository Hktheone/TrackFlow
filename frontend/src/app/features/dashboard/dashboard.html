How an order moves

  1. 1
    Order placed

    REST call through the gateway to order-service. Status Pending.

  2. 2
    Order confirmed

    order-service publishes ORDER_CONFIRMED to order-events.

  3. 3
    Delivery created

    delivery-service consumes it, creates a delivery; the customer then picks a rider.

  4. 4
    Status flows back

    Every delivery update goes to delivery-status-events; order-service mirrors it.
